# Release 2026-06-09

## Packages

| Package | Version |
| ------- | ------- |
| `@trackdigger/web` | `0.3.2` |
| `@trackdigger/python-service` | `0.3.1` |

## Highlights

A stability and quality pass. The SoundCloud seed is now validated with the shared query-match scorer so fuzzy hits no longer poison recommendations, the last uncached Last.fm path picks up a 7-day cache, and two crash/loop bugs in the player and discography views are fixed. Discography also gains a first-class artist model and endpoints. This release invalidates the `/similar` result cache (bumped to v14).

## Changes

### New Features

- **Artist model and discography endpoints** — a new Prisma `Artist` model plus `artistById` / `artistSearch` server endpoints, wired into the discography page (`web/features/discography/server/`, migration `20260521000000_add_artist_model`).

### Bug Fixes

- **SoundCloud seed validation** — the search seed is now scored with the shared query-match scorer before fetching recommendations, so a fuzzy hit like a label-uploaded DJ mix no longer becomes the seed and an unvalidated query contributes nothing (`swift-pumas`).
- **YouTube player onReady gate** — seek/toggle/poll now wait until the iframe fires `onReady`, fixing a `seekTo is not a function` crash when dragging the progress bar before the player finishes loading (`yt-player-ready-gate`).
- **Discography infinite render loop** — opening discography from a track card crashed with "Maximum update depth exceeded"; `fetchFn` / `onSelect` are now wrapped in `useCallback` so their identities stay stable across re-renders (`web/features/discography/components/DiscographyPage.tsx`).
- **Anonymous request limit** — now resets on a sliding 24-hour window per IP, so unauthenticated users get 5 free requests per day instead of 5 for life (`anon-daily-reset`).
- **Persist label/discography page state** — search input and selected entity now survive route navigation, hoisted from local `useState` into the existing `labelsAtom` / `discographyAtom` (`persist-label-discography-state`).

### Performance

- **Last.fm `track.getSimilar` cache** — the last uncached Last.fm path now caches results for 7 days (`swift-pumas`).
