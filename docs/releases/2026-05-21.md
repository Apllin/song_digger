# Release 2026-05-21

## Packages

| Package | Version |
| ------- | ------- |
| `@trackdigger/web` | `0.3.1` |

## Highlights

A deep upgrade to search quality. A new **lastfm_hop** source fans out across artist-similarity graphs to surface niche tracks that streaming recommenders miss, artist-only search now queries all seven sources instead of four, and seed matching is stricter so queries no longer latch onto the wrong artist. This release invalidates the `/similar` result cache.

## Changes

### New Features

- **lastfm_hop source for `/similar`** — multi-seed artist-similarity fan-out from the query artist plus top trackid co-occurrence artists, surfacing ~18 additional niche tracks per request (`python-service/app/services/lastfm_hop.py`). Adds Prisma migration `20260518000000_add_lastfm_hop_source` and is wired into the training pipeline.
- **Artist-only search now fans out across all 7 sources** — Last.fm, the trackid keyword flow, and the lastfm hop join the previously cosine/ytm/yandex/soundcloud-only path (`python-service/app/api/routes/similar.py`).
- **trackid keyword flow** — a new `/audiostreams?keywords=` lookup returns the tracks a DJ plays in their sets (~47 unique adjacent artists for a typical artist query) (`python-service/app/adapters/trackidnet.py`).
- **`YANDEX_MUSIC_ENABLED` flag** — the Yandex Music adapter is disabled by default (it is geoblocked on non-RU IPs) and is now opt-in via environment variable (`python-service/app/config.py`).

### Bug Fixes

- **Stricter seed matching** — bare-artist queries require an exact-entity artist match rather than a substring match, so "Rill" no longer seeds off "Rill Saionji" (`python-service/app/adapters/_seed_match.py`).
- **trackid seed picker** — no longer drops tracks with `playCount=0`; that field is unreliable on `/musictracks`, and niche tracks with real playlist history were being lost.
- **trackid solo-reprocess fallback** — when the seed appears only in a solo reprocess, the adapter falls back to the largest detection process instead of returning nothing.
- **SoundCloud noise filtering** — DJ-set, podcast, and radio-show uploads are dropped via title regex plus a seed-duration check (a seed over 20 minutes skips the source entirely).
